# Repository Release Manifest

## 1. Scope

This repository provides the scientific implementation, input datasets, experimental configuration, reference results, and publication analysis for:

**Multi-Objective HAPS Placement for Improved GNSS Positioning in Dense Urban Environments**

ACDSA 2027 — Rio de Janeiro, Brazil, 2–4 February 2027.

The repository represents the experiment described in the finalized manuscript, covering Shinjuku, Downtown Dubai, and Frankfurt Bankenviertel.

## 2. Repository contents

| Path | Contents |

The `inputs` symbolic link provides the input path expected by the experimental notebook.

## 3. Scientific implementation

The numerical experiment uses the scientific implementation and configuration validated against the camera-ready results.

The following are preserved:

- GNSS and HAPS geometry calculations and positioning-state model.
- Four-HAPS placement parameterization and search constraints.
- Greedy, Differential Evolution, NSGA-II, and structured placement procedures.
- Optimization budgets, seeds, numerical parameters, and stopping conditions.
- DESIGN/TEST partitioning and DESIGN-only representative selection.
- Recovery and PEB95 definitions, including the common-population metric.
- Scientific input datasets and their recorded checksums.

Editorial revisions to the notebooks are restricted to Markdown and Python comments. The executable statements and scientific control flow are preserved.

## 5. Input and result integrity

Scientific input checksums are recorded in `config/experiment.json` and the accompanying input manifest.

The original reference results are provided under `reference_results/`. These are separate from outputs generated by a new reproduction.

Source-file and notebook integrity checks establish equivalence with the verified scientific implementation. A final checksum inventory should be generated after the editorial review is complete.

## 6. Excluded materials

The release excludes intermediate working caches, incomplete experimental artifacts, temporary test files, machine-specific execution logs, local virtual environments, and private computing infrastructure configurations.

These materials are not required to interpret or reproduce the published scientific experiment.
